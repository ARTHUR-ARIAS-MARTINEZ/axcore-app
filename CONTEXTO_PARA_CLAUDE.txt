▌ CÓMO HACER QUE LOS CAMBIOS APAREZCAN EN LA APP (CRÍTICO)

   Cada vez que se hace un cambio importante en CSS o JS,
   HAY QUE BUSTING DE CACHÉ o los atletas no verán nada:

   1. En index.html cambiar la versión del CSS:
      <link rel="stylesheet" href="index.css?v=20260517a">
      → bump a 20260517b, 20260517c, etc.

   2. En index.html cambiar la versión del JS:
      <script src="app.js?v=20260517a"></script>
      → bump igual

   3. En coach.html cambiar la versión del CSS también.

   4. En sw.js cambiar CACHE_NAME:
      const CACHE_NAME = 'axcore-v3.2-mobile-pro';
      → bump a v3.3, v3.4, etc.

   5. Hacer commit y push:
      git add . && git commit -m "..." && git push origin main

   6. Esperar 1-2 minutos para que GitHub Pages despliegue.

   7. En el celular: cerrar la app 2 veces (la primera carga el
      nuevo Service Worker, la segunda lo activa).
      O usar VISOR_MOVIL.html con cache-busting automático.
